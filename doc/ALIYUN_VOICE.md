# 阿里云自然朗读

管理员进入“设置 → AI 渠道”，在“阿里云自然朗读”填写北京地域百炼 API Key、业务空间 ID，勾选启用并保存。默认龙小夏讲题女声，可改龙小淳女声或龙安洋男声。点击“保存并试听”核对音色、账号权限与额度；试听也按量计费。请使用 HTTPS 或 SSH 安全隧道填写密钥，不要通过公开 HTTP 提交。密钥保存在服务器 config/app-config.json，不进入 App、不入 Git，API 只返回掩码。备份配置文件时需保密。

- 协议：CosyVoice HTTP，cosyvoice-v3-flash，北京业务空间专属域名。
- 自动选择：启用阿里云时使用自然语音，否则使用原有兼容语音；也可手动选择自然、设备或兼容语音。自然语音故障会明确报错，不会偷偷换成机械声音。
- 手机不需要代理；App 直接播放本系统返回的 WAV，不需重新安装。语速、暂停、重听、连贯讲解仍可用。
- 选择设备语音时立即检查可用音库，无可用声音时显示切换提示。
- 讲解文字会发送阿里云；讲题音频按文本、模型、音色、合成语速等参数持久保存，同内容复用；详见 [音频持久化](PERSISTENT_AUDIO.md)。阿里云返回的临时下载地址有其自己的有效期。
- 保留本人内容校验、到期/停用限制、每用户每分钟60段、全局2个并发。只允许已答题/本人错题的服务器原文，不能提交任意合成正文。
- 可选环境变量 DASHSCOPE_API_KEY、DASHSCOPE_WORKSPACE_ID；界面设置优先。文本、模型、音色或合成参数变化时生成新音频，密钥轮换不导致已有音频重新合成。

官方接口：https://help.aliyun.com/zh/model-studio/cosyvoice-tts-http-api
音色：https://help.aliyun.com/zh/model-studio/cosyvoice-voice-list

旧数字业务空间 ID 使用阿里云官方 DashScope 兼容域名；API Host 形式的空间 ID 使用北京专属域名。
