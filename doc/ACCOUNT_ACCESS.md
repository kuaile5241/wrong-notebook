# 注册账号、权限与使用期限

入口：管理员后台 → 账号与授权（`/admin/users`）；设置 → 用户管理中也可操作。

- 打开“允许新用户注册”后，注册账号自动出现在列表中。注册默认是启用的普通账号、原有功能权限、不限时；可按账号设置权限和期限，旧账号保持原状态。
- “权限与使用时间”可设置管理员/普通账号、启停、允许AI、允许数据导入导出；管理员拥有完整功能权限。停用管理员账号同样不能登录。
- 有效期按操作设备的时区填写，保存为绝对时间；列表按应用时区显示。支持不限时与延长1/7/30天。未到期从原时间顺延，已到期从当前时刻计算。
- 普通账号在截止时刻起不能登录、访问页面或调用接口。已有会话也被服务端实时拦截；已打开页面到期会跳转提示。管理员修改期限后，原账号即可重新登录使用，题目数据不会删除。
- 当前管理员与主管理员受保护，不允许自行锁定；最后一个启用管理员不能降级、停用或删除。
- 账号授权由数据库实时判断，客户端传入的角色、过期时间以及旧JWT不能覆盖管理员决定；校验服务不可用时拒绝访问。
- API Key/用户名密码的Openclaw集成同样检查目标账号有效性与AI权限。已发起的请求不因用户随后到期而强制中断，但到期后的新请求会被拒绝。
- 备份导出包含账号权限元数据；数据导入不恢复账号角色和访问权限，避免普通用户通过旧备份自行续期。恢复学习数据后，管理员可按备份元数据在后台重新授权。
- 网页版与在线安卓客户端共用这些规则，无需重新安装APK。
