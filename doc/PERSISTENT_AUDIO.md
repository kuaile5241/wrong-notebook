# 讲题音频持久保存和复用

- 完成的 WAV 原子写入 `data/lesson-audio/<SHA256>.wav`，默认位于应用数据目录。Docker 家庭版挂载 `/app/data`，容器重建后仍保留。可用 `LESSON_AUDIO_CACHE_DIR` 指定其他持久目录。无自动到期或定时删除，不生成视频。
- 缓存键只取实际讲解文本、提供商/模型、音色、合成语速、采样率和格式。相同内容跨已鉴权账号复用，轮换密钥、重登、播放、暂停、重听、切步不使缓存失效。页面0.75/1/1.25倍速由播放器本地调整，不调用 TTS；将来修改合成语速时才产生另一份音频。第一次遇到尚未生成的步骤需要生成一次。
- 并发相同请求共用一个 Promise，并以磁盘锁防止独立进程重复生成。用户取消播放或关闭页面只停止接收/播放，服务端已开始的任务继续完成保存。实际生成才写入 `Generating new lesson audio` 日志，仅记录哈希与非敏感配音参数，不记录密钥或讲稿。
- 缓存文件只通过本人题目/已提交作答的音频接口读取，不提供公开文件 URL。仍校验账号停用/有效期、内容版本及限流。音频目录700、文件600；请保护数据备份。
- 缓存损坏不自动付费重生成；保存失败明确报错，同一进程内不会因重试重复合成，需要管理员检查存储。只保证已完成且成功保存的音频可长期复用；上游失败、系统在生成/保存前异常退出时不存在可复用成品，不能把这类失败承诺成“永久只收费一次”。
- 音频文件随 `data/lesson-audio` 目录备份，数据库 JSON 导出不包含音频二进制。迁移站点时需一起迁移该目录；仅导入题目 JSON 而不迁移音频文件，首次播放需要重新生成。没有新增数据库字段或迁移。
- 不自动清理意味着目录会随讲稿与音色版本增长，管理员按实际磁盘容量保管。旧版本音频保留，改回原音色和文本仍可复用。
