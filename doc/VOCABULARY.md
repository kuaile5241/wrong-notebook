# 英语词汇图鉴

导航“英语词汇”进入 /words。接入 Word Atlas 7298 个词条、19 个主题的插画、英美发音和例句录音。词库文字/插画/录音按 CC BY 4.0 署名，内容由上游AI生成，未逐条经教师审核；完整来源、版本与许可在 resources/vocabulary。

## 学习方式

- 小学为筛选后的基础推荐词；初中拓展 A1—B1、高中拓展 A2—B2，全部词库可选 A1—C2。学段是筛选建议，不是官方年级标准或教材目录。现已增加鲁教湘教版三上教材目录与参考词汇，逐词复核待完成，见[教材书架](TEXTBOOKS.md)。
- 词卡含插画、两种口音、主要释义、第一条例句及其录音；展开可看其他释义、例句、搭配与提示。其他例句可能更难，不把A1词的所有例句都视为儿童难度。
- 支持看词选义、听音辨词、拼写和回忆自评；每道练习首次提交才计分和排期。重复提交返回已有结果，同词陈旧练习或超过24小时的题返回409。使用账号排队和数据库版本条件防止重复更新。
- 客观题服务端判分；自评单独计数，不计入客观正确率。听辨题不在题面附带答案，词典本身仍可查阅，不作为严肃考试防作弊。
- 收藏、学段/能力/主题/口音/每日目标按账号同步。搜索词和当前分页不长期保存。
- “今日练习”在当前学段、能力、主题中优先到期词，再选未复习词；每日目标按当天复习次数显示，不强制锁定额外练习。可直接练指定单词。
- “错词记录”保留曾客观答错的词，便于补练，不等于当前未掌握判断，也不会把每个词塞入原错题本。
- 词汇FSRS复习独立于数学等错题计划。默认目标保留率0.9；正确按Good、错误按Again，自评可选1—4级。进度只表达练习线索，不证明已经永久掌握。

## 账号和备份

所有词汇API（包括图片/录音）实时校验账号，停用/到期立即限制新请求。普通词汇学习无需AI权限，不调用付费TTS或大模型。固定录音支持Range、暂停、重听及本地倍速；录音缺失时提示错误，不降级到机械设备语音。

正式迁移 20261031085721_add_vocabulary_learning 新增 VocabularyCard、VocabularyAttempt，以及 User.vocabularySettings；仅新增表和用户字段，不重建原用户表。

原有JSON备份新增 vocabularyCards、已完成的 vocabularyAttempts 和本人词汇偏好；媒体不嵌入备份，未提交练习属临时数据不导出。导入校验词条/FSRS状态与计数，重算已答判分；普通导入过滤其他账号记录，不覆盖现有新进度。公开词库和媒体无需按账号复制，删除账号级联删除私有词汇记录。

## 媒体安装与部署

固定上游提交：99c007673d38f02c418d8e4cd2e9ec90b5d40be5。37501份图片/录音约651MB，独立安装，避免每次业务更新重复打包。先检出该提交，再执行：

```sh
python3 scripts/install-vocabulary-media.py --source /path/to/word-atlas/public/atlas --output /opt/wrong-notebook/assets/word-atlas-99c0076
```

脚本逐一按 resources/vocabulary/media-manifest.json 校验SHA256及字节数，只创建新目录，不覆盖已安装资源。将输出目录只读挂载至 /app/resources/vocabulary-media；也可通过 VOCABULARY_MEDIA_DIR 指定。新镜像包含 resources/vocabulary 的文字与清单，不能把它放在被 /app/data 挂载遮蔽的位置。

原 /app/data/lesson-audio 为讲题持久音频，和本模块的固定词汇录音各自保存；部署不得清理或改写原讲题缓存。

资源自身不依赖作者网站或用户代理，实际速度取决于本机/服务器网络。原安卓在线客户端重新打开网页后使用，无需因本次网页功能重装；尚未宣称实体安卓设备验收。

教材未匹配词条可在明确点击后使用既有自然语音并持久保存，详见[教材说明](TEXTBOOKS.md)。
