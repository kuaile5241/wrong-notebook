# Remember learning homepage selections

Subject, grade/volume, chapter and question count are stored per account in the current browser/app. Returning, refreshing or reopening restores the last choices. The catalog is fetched only after restoring the authenticated account's preferences, so defaults cannot overwrite them. Accounts remain isolated.

Changing subjects clears the prior volume/chapter; changing volumes clears the chapter. Normal navigation preserves selections. Search text is not permanently stored and explicit search links remain effective. Removed catalog options fall back safely.

No app reinstall or database migration is needed. This is device/browser storage rather than cross-device cloud sync. Clearing app/site data clears preferences; storage restrictions do not break the page.
