# 在线练习与基础诊断

在导航进入“在线练习”，选学科、册次、章节或搜索知识点。支持单点/章节练习和基础诊断，每次最多 5/10/20/30 题；知识点题量不足时按实际题量完成，不重复凑题。

- 提交后显示参考答案和解析；数值/选择题用规则判分，不消耗 AI 额度。未知表达式和开放题对照答案自评。
- 答错或“不会”自动归入自己的错题本并安排次日复习；相同来源题复练只新增作答记录。正确题不会预先填满错题本。
- 诊断沿硬先修追查，连续答对两题作为本次通过线索；“推测已会”“不稳定”“薄弱”“待确认”分别显示，不能代替完整测评。
- 学习进度保存在账号下，可刷新继续、跨设备打开，也包含在原有数据导出/导入中；导入按原题与作答重建，不信任备份答案或状态。
- 账号停用、到期即时限制新接口；允许普通题库练习不要求 AI 权限。所有历史记录按用户隔离。
- 数据固定在 resources/learning，不在公开静态目录，不实时请求 GitHub。来源 ID 不覆盖已有同名标签，错题使用册次和知识点 ID 关联。
- 内容包含数学、英语、物理、小学语文/科学/道德与法治及初中历史，共 2938 点、11899 题。部分教材映射待核，内容为 AI 初稿，页面明确提示试用。
- 许可：第三方数据和引擎 CC BY-NC 4.0，保留来源、许可链接和修改声明；个人非商业学习使用，付费运营另行取得授权。详见 resources/learning/NOTICE.md。

视频暂未接入。后续可增加知识点/单题 NAS 课程，或文字解析配语音和分步动画，不影响现有学习记录。

部署必须执行正式迁移 20261030033211_add_learning_sessions。家庭 Docker 构建显式复制 resources/learning，避免被 /app/data 持久化挂载遮蔽；Next standalone 也配置了文件跟踪。

[解析朗读与分步讲解](SPOKEN_LESSONS.md)已接入练习反馈、历史记录和错题详情，视频继续暂缓。

## 完整图谱和诊断功能

入口/knowledge：学段/年级册次/领域/名称章节编号检索，完整树形目录，软硬先修图，向上1/2/3/全部与下游一层、缩放拖动适配、节点跳转，完整领域类型掌握标准、791条课标说明与数学关联、显式展开学习样题。所有现有课标引用可匹配条文；保留待核声明。练习目录有真实分页及全量scopeTopicIds，不再只显示前100项而无法继续。

目标诊断与范围整体筛查独立：筛查只在所选范围内（可整册/按章/当前筛选），连续确认可选2/3/5，题量最多60。完整结果含已答/薄弱/不稳/已掌握（含推断）/未测、按章汇总、可能根因及未测/范围外先修提醒、由基础到目标的路径与路径图。结果支持继续增加最多10题、撤销上一题、更正作答、重新开始新会话、独立JSON、分享PNG和打印/PDF。

更正会截断该题之后的分支并重算，后续需重答；撤销/更正不会删除已归档错题或过去练习记录。新会话使用原版软硬关系（engine.graphMode=full），旧记录仍按旧硬先修图重放、续答，不能简单把旧会话套用新规则。

/learn/profiles提供账号内多孩子档案（称呼、年级、选择、归档/恢复），进度、盲区、错题来源按档案隔离。旧会话profileId空字符串作为原有默认档案。档案与会话进入原JSON备份，已有档案/会话不覆盖，普通导入不混入其他源用户记录。迁移20261031134643_add_learning_profiles仅给User加learningSettings、LearningSession加profileId，不重建原表。仅账号持有人能访问档案和报告，停用/到期立即限制。

此前固定快照2938点/11899题/4380关系现独立保留，用于已有记录续答。课标说明和ID别名来自当前固定快照07941bc；元信息纳入manifest哈希。原站推广、统计和Service Worker不复制到本系统。
