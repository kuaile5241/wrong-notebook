# 在线练习与基础诊断

在导航进入“在线练习”，选学科、册次、章节或搜索知识点。支持单点/章节练习和基础诊断，每次最多 5/10/20/30 题；知识点题量不足时按实际题量完成，不重复凑题。

- 提交后显示参考答案和解析；数值/选择题用规则判分，不消耗 AI 额度。未知表达式和开放题对照答案自评。
- 答错或“不会”自动归入自己的错题本并安排次日复习；相同来源题复练只新增作答记录。正确题不会预先填满错题本。
- 诊断沿硬先修追查，连续答对两题作为本次通过线索；“推测已会”“不稳定”“薄弱”“待确认”分别显示，不能代替完整测评。
- 学习进度保存在账号下，可刷新继续、跨设备打开，也包含在原有数据导出/导入中；导入按原题与作答重建，不信任备份答案或状态。
- 账号停用、到期即时限制新接口；允许普通题库练习不要求 AI 权限。所有历史记录按用户隔离。
- 数据固定在 resources/learning，不在公开静态目录，不实时请求 GitHub。来源 ID 不覆盖已有同名标签，错题使用册次和知识点 ID 关联。
- 内容包含数学、英语、物理、小学语文/科学/道德与法治，共 2804 点、11363 题。部分教材映射待核，内容为 AI 初稿，页面明确提示试用。
