# 解析朗读与分步讲解

在线练习提交后的解析、历史作答以及错题详情的“解析”卡片，支持“听一听，分步学”。

- 保留原解析与数学公式，按段落、编号和句子分步，不生成新的解题结论；配图显示题目原图。可选上一步/下一步或点击步数，完整解析仍可展开。
- “听这一步”“连贯讲解”“暂停”“再听一遍”，支持0.75/1/1.25倍速。切步、换题、离开页面或切到后台停止朗读。
- 自动选择优先使用已启用的阿里云自然语音，否则使用兼容语音；设备语音可手动选择，不可用时立即提示。设备暂停后可能从当前短句重新开始；兼容音频暂停后可继续。
- 兼容语音由服务器容器内独立的eSpeak NG程序生成，音色较机械，不是自然人配音；支持中英文。仅生成短WAV，最多8MB内存缓存、10分钟过期，不落盘、不生成视频，不消耗AI额度。首次播放受设备限制时，按页面提示再点“继续朗读”。
- 常用分数、平方、根号、百分数与运算符转换为读法；未知TeX命令提示对照屏幕，不保证复杂公式朗读完整，以屏幕原式和原解析为准。
- 音频接口从本人错题或已经提交的学习记录取原文，不接受任意正文；未提交题目答案不可访问。账号停用/到期即时拒绝，内容变更时需刷新后重听。每账号每分钟60段、全局最多2个生成任务。

部署：家庭镜像和标准Docker镜像安装espeak-ng；其他部署方式需要在应用运行环境安装同名程序，否则设备语音仍可用，兼容语音提示不可用。可选接入阿里云付费自然语音，密钥由管理员配置；没有新增数据库字段或迁移。API为POST /api/lesson-audio。

语音引擎：https://github.com/espeak-ng/espeak-ng （独立系统程序及其自身GPL许可；应用不链接其库）。Web Speech兼容依据：https://github.com/mdn/browser-compat-data/blob/main/api/SpeechSynthesis.json 。第三方题库继续遵循原CC BY-NC 4.0范围。
