# 公式朗读与动画配音

- 先把常见算式转换为明确读法，再交给语音服务。例如 `40-12=28`、`４０－１２＝２８` 都转换成“四十减去十二，等于二十八”。覆盖普通/全角等号、加减乘除、不等号、分数、百分数、幂及常用 TeX；未知 TeX 明确提示看屏幕。纯数字算式默认中文。页面可展开“查看本步朗读文字”。转换不会重新求值或改动屏幕公式。
- 语音分段上限从150增至450字符，优先在完整句末分段；连续模式在当前段播放时预取下一段，减少段间等待。暂停、切题、离开时停止并清理预取。首次准备和网络异常仍可能等待。
- 新增龙小夏讲题女声作为默认，保留原女声和男声。音色自然程度因人而异，可在管理员设置试听切换。
- 题目详情的 SVG 动画下方新增详细语音讲解，可连贯播放、暂停、调速和选步。音频进度驱动该步 SMIL 时间轴，讲稿较长时动画随语速放慢，不会先播完；进入后台暂停。
- 新生成动画由同一 AI 请求同时生成图形与每步讲稿，在根元素内用 `<desc data-voice-start="0" data-voice-end="5">讲稿</desc>` 保存。讲稿描述目的、理由、计算和结论，与当前语言一致。现有动画按原题/原解析/原答案配音，可重新生成获得逐场景讲稿。旧动画均匀映射原解析步骤，不能保证原画面与语义逐字对应，界面明确提示。
- 配音接口只读取本人数据库中对应语言的动画和讲稿，并校验指纹、账号有效期和频率。客户端不得提交任意讲稿；画面或讲稿变更后旧指纹失效。讲稿随既有 SVG 字段导出/导入，无新增表或迁移。过长、重叠、越界的讲稿元数据回退到原解析。
- 音频仍走阿里云百炼，讲解文本会发送服务并按量收费；音频不在服务器落盘。此次音色验收使用短样本合成及语音识别回查，不等于保证任意复杂公式永不读错。
