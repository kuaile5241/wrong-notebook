# 题目自动生成讲解视频

错题详情的“生成讲解视频”会读取该题的题干、答案和解析，调用当前AI模型编写结构化分镜，再由独立的Papermorph渲染容器生成自然配音动画MP4。完成后在该题下直接播放和下载。支持四则运算、简单方程、假设法、条形图、数轴和真分数等可视模型；复杂几何等题型会返回暂不支持的原因。

## 制作过程

- 每次内容、模型、音色与渲染版本相同时按用户及题目去重，同一生成结果持续复用。
- 使用Papermorph引擎342e272648e06a6163224a6177bccc83517d7fea进行逐帧动画，960×540、12fps。输入仅为校验后的JSON，不执行模型返回的程序。
- Edge TTS 7.3.1生成配音，文本先经过现有数学符号朗读处理，音频按文本、音色和语速永久缓存。失败重试复用已保存分镜和音频。
- 基础纯数字算式会在渲染前重新计算等号两边。生成内容仍需结合原题核对。
- 模型写稿计入现有AI额度；配音使用Edge在线服务，连接失败会提示并允许重试。

## 独立渲染服务

使用packaging/video-worker/Dockerfile构建镜像，将正式数据目录挂载为/data，不暴露端口；限制CPU、内存和进程数。主网站负责鉴权、分镜和队列，渲染器只有题目分镜数据，无模型密钥。

持久数据包括 data/video-jobs、data/edge-video-audio、data/lesson-videos 和SQLite中的VideoGeneration表。完整备份应同时包含这些目录。网页JSON备份包含生成记录，恢复后仅在归属凭据匹配且媒体存在时复用完成结果，其他记录等待用户重试。

队列状态在SQLite中持久保存，音视频文件用临时文件和原子重命名发布；渲染文件锁跨进程去重。服务中断时原有成品保留，后续重试复用缓存。

本功能使用Papermorph MIT引擎，许可见packaging/video-worker/engine/LICENSE。Edge TTS与Playwright按各自开源许可使用。
